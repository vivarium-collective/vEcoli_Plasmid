1. Project Overview

This report documents the development of a mechanistic plasmid replication process for the vEcoli whole-cell model (WCM), based on the ColE1-type replicon (pBR322, GenBank J01749.1, 4,361 bp). The core biological mechanism — RNA I/II copy number control — was modelled using the quantitative framework of Ataai & Shuler (1986).

To study resource competition between the plasmid and chromosome — a key biological question — the mechanistic_replisome option was enabled. In this mode, replication initiation requires a minimum count of DnaG (DNA primase) and helicase complexes. This surfaced a multigenerational DnaG depletion problem: DnaG is initialized correctly in generation 1 (matching experimental proteomics data of 6–20 molecules/cell), but its count progressively drifts downward across generations due to compounding regulatory errors, reaching ~0–1 molecules/cell by generation 5–6. Once the mechanistic gate is enforced, this depletion directly causes a TimeLimitError at generation 6. The vEcoli default is non-mechanistic, which silently allows replication to proceed even when DnaG falls below the required minimum. A detailed investigation traced the drift to multiple compounding errors in the model's regulatory data pipeline.

Scope

  • Plasmid replication process with three modules: initiation, elongation, termination
  • RNA I/II copy number control (Ataai-Shuler ODEs integrated at each timestep)
  • Mechanistic replisome: chromosome and plasmid share the same subunit pool (DnaG, DnaB, etc.)
  • Non-mechanistic vs mechanistic comparison: why the default was non-mechanistic
  • Multigeneration simulation failure at generation 6 — diagnosis and partial fix

2. The mechanistic_replisome Flag — Context & Motivation

What the flag controls

The chromosome replication process (ecoli/processes/chromosome_replication.py) and the plasmid replication process contain an optional subunit availability gate governed by the mechanistic_replisome boolean:

ModeConfig valueBehaviour
Non-mechanistic (default) "mechanistic_replisome": false Subunit availability check bypassed. Replication initiates whenever a free oriC/oriV exists, regardless of how many DnaG or helicase complexes are in the bulk pool. Cells always divide on schedule.
Mechanistic "mechanistic_replisome": true Initiation requires n_trimers ≥ 6 × n_oriC and n_monomers ≥ 2 × n_oriC. If either condition fails, replication stalls. If stalling persists beyond the 3-hour simulation limit, a TimeLimitError is raised and the lineage terminates.

The default is non-mechanistic — and why that likely matters

The vEcoli model ships with mechanistic_replisome: false as the default (see ecoli/library/sim_data.py, line 50: mechanistic_replisome: bool = False). This means baseline multigeneration simulations proceed without enforcing subunit stoichiometry at the initiation step.

Working hypothesis — the default was set to avoid a latent DnaG depletion problem As the investigation in Sections 7–9 below reveals, DnaG is correctly initialized in generation 1 (consistent with proteomics data: 6–20 molecules/cell across three independent datasets). However, due to compounding regulatory errors in the model's data pipeline, DnaG progressively depletes across generations and reaches ~0–1 molecules/cell by generation 5–6. With the mechanistic gate enforced, this multigenerational drift directly blocks replication initiation and causes a TimeLimitError. The non-mechanistic default allows cells to divide on schedule regardless — the depletion occurs silently, with no observable consequence at the cell level. Whether the default was set deliberately for this reason is uncertain, but the consequence is clear: switching to mechanistic mode immediately exposes the bug.

Why the mechanistic option was turned on for this work

The goal of this project is to model resource competition between the chromosome and a ColE1 plasmid. Plasmids use the same replisome subunit pool as the chromosome (shared DnaG, DnaB helicase, tau complex, clamp loader). To study whether the plasmid draws down subunits and affects chromosome replication — and vice versa — the mechanistic check must be active. Without it, both chromosome and plasmid replication proceed unconstrained regardless of subunit availability, and the competition question cannot be answered.

The mechanistic flag was therefore set to true in configs/multigen_ecoli.json and configs/plasmid_in_ecoli_new.json: 

// configs/multigen_ecoli.json
{
  "experiment_id": "multigen_ecoli_dnag_fix",
  "mechanistic_replisome": true,
  ...
}

3. The Ataai-Shuler Copy Number Control Model

ColE1 plasmid replication is controlled by two RNA species transcribed from the plasmid itself:

  • RNA II — the primer transcript. RNAP initiating at the RNAII promoter transcribes a ~600 nt RNA that, if not intercepted, folds into a structure at the origin and primes DNA replication.
  • RNA I — the inhibitor. Transcribed in the opposite direction, RNA I hybridises with the 5′ end of nascent RNA II, preventing primer formation. Higher copy number → more RNA I → more inhibition → fewer initiations. This is the feedback loop that sets the steady-state copy number.

Ataai & Shuler (1986) formalised this as a set of coupled ODEs and fit the rate constants to experimental data from pBR322-carrying E. coli.

ODEs

dRNA_I / dt = α_I · N − k_h · RNA_I · RNA_II − γ_I · RNA_I
dRNA_II / dt = α_II · N − k_h · RNA_I · RNA_II − γ_II · RNA_II
dH / dt = k_h · RNA_I · RNA_II − γ_H · H

Where N is the current plasmid copy number, H is the RNA I:RNA II hybrid, and all other symbols are rate constants from Table 1 of Ataai & Shuler (1986). At steady state with N ≈ 23 copies/cell (their prediction for pBR322 in minimal glucose):

  • RNA I ≈ 3 molecules/cell
  • RNA II ≈ 0 (rapidly hybridised)

Initiation Criterion

Each plasmid fires an RNA II initiation attempt every 1 / αII = 360 s. The fraction of RNA II transcripts surviving RNA I binding in τ = 7 s (transcription time to origin) is:

P(survival) = exp(−k_h · RNA_I · τ)

Of those, a primer efficiency f = 0.5 fraction form functional primers and initiate replication. The expected number of new initiations per 360 s window is therefore:

ΔPL = N · f · exp(−k_h · RNA_I · τ)

The paper treats PL as continuous; in the WCM we accumulate the fractional expected new plasmids (PL_fractional) and fire integer initiations when the accumulator crosses 1.0, carrying the remainder forward.

4. Implementation in plasmid_replication.py

The process is implemented as a PartitionedProcess in ecoli/processes/plasmid_replication.py. It is structurally adapted from the chromosome replication process but uses unidirectional replication (one fork per oriV, not two) and replaces the DnaA-based chromosome initiation with the RNA I/II control mechanism.

Process Ports

PortSchemaContents
bulknumpy_schemaReplisome subunit counts, dNTPs, PPi
full_plasmidsunique moleculeCompleted plasmid copies
oriVsunique moleculeOrigins of replication (one per active plasmid)
plasmid_active_replisomesunique moleculeActive replication forks with position coordinates
plasmid_domainsunique moleculeReplication domain tree (tracks parent/child relationships)
plasmid_rna_controlprocess_stateRNA I, RNA II, hybrid counts; PL accumulator; time counter

Three-Module Structure

Module 1 — Replication Initiation (evolve_state lines 464–643)

Identifies idle plasmids (full plasmids without an active replisome). Gates initiation through two independent checks:

  1. Subunit gate: max_new_replisomes = min(trimers // 3, monomers // 1). Each new replisome consumes 3 trimer subunits and 1 monomer subunit.
  2. RNA control gate: n_rna_initiations computed in calculate_request from the Ataai-Shuler equations and passed through process_state.

New oriVs, domains, and replisome entries are added; replisome subunits are decremented from bulk.

Module 2 — Fork Elongation (lines 644–719)

Uses buildSequences + polymerize (same infrastructure as chromosome replication). The plasmid sequence is tiled as two copies (both strands) per active replisome. dNTPs are consumed proportionally; fork coordinates advance by the number of bases polymerised.

Module 3 — Termination (lines 721–826)

When a fork's coordinate reaches or exceeds the replichore length (4,361 bp for pBR322), the replisome is deleted, replisome subunits are returned to bulk, and a new full_plasmid entry is created with a fresh domain index. The parent plasmid's domain index is updated to the first child domain.

Key Design Decisions

Unidirectional replication ColE1 plasmids replicate unidirectionally from a single ori. This required setting right_replichore = False for all new replisomes and using only one sequence tile per plasmid rather than two (as in bidirectional chromosome replication).
RNA I/II computed in calculate_request The ODE step and initiation criterion are evaluated inside calculate_request rather than evolve_state. This ensures that n_rna_initiations is written to process_state before evolve_state runs, allowing the Requester to pass the initiations count through the allocator cycle without an extra timestep delay.
Fractional accumulator for sub-integer initiations At typical plasmid counts (~23) and small timesteps (1 s), each 360-s window produces ΔPL ≈ 23 × 0.5 × exp(−k_h × 3 × 7) ≈ a few initiations per window. Accumulating fractions and firing integer events preserves the correct long-run average without requiring Poisson sampling.

7. Multigeneration Simulation Failure at Generation 6

Observed failure Multigeneration simulations (both with and without plasmids) fail with a TimeLimitError at approximately generation 6. The cell exceeds the 3-hour maximum simulation duration without dividing. The cause: replication initiation fails because the required replisome subunits — specifically DnaG (DNA primase) — drop to 0–1 molecules/cell, below the minimum of 2 required per oriC.

8. DnaG Investigation — Step by Step

Step 1 — Trace the fold change origin

fold_changes_nca.tsv contains lexA → dnaG = −1.71 log₂. This comes from the NCA (Network Component Analysis) pipeline in reconstruction/ecoli/scripts/nca/fold_changes.py:

  • EcoCyc provides the regulatory topology (lexA represses dnaG, direction = "−")
  • EcoMAC (4,189 genes × 2,198 conditions, Carrera et al. 2014) provides expression data
  • NCA factorises the expression matrix: E ≈ A · P; fold change = A[dnaG, lexA] × (mean_high_P − mean_low_P)
Critical finding The "low lexA activity" conditions in EcoMAC are dominated by norfloxacin (SOS-inducing) experiments, where lexA is fully cleaved by RecA. The fold change magnitude of −1.71 log₂ represents the maximum SOS de-repression signal — not the natural range of lexA activity during normal growth. This fold change was never included in the manually curated fold_changes.tsv, suggesting prior awareness of its uncertainty.

Step 2 — Examine the 0CS fitting problem

LexA is a 0CS (zero-component system) TF in the model. Its binding probability is set to p_bound = min(1, TF_count / n_targets) ≈ 1 whenever any lexA molecules exist. It is never inactivated at runtime — the SOS response (lexA cleavage by RecA) is not modelled. The parca fitting therefore:

lexA active condition: r_α + 1 × r_lexA = X (basal expression) lexA inactive condition: r_α + 0 × r_lexA = 3.27 × X (lexA knockout) ⟹ r_α = 3.27X, r_lexA = −2.27X

At runtime: effective = 3.27X + (−2.27X) × 1 = X. The fold change mathematically cancels, but introduces large compensating terms that amplify stochastic errors for a low-copy gene like DnaG.

Step 4 — Map the lexA operator against each TU

The rpsU-dnaG-rpoD operon has three transcription units in EcoCyc, each with a different TSS corresponding to a different promoter:

LexA operator position: 3,210,729 – 3,210,748 (EcoCyc). For a repressor to block a promoter, the operator must overlap the −10/−35 boxes or the TSS. TU00352 and TU00434 have TSSs upstream of the operator — RNAP has already initiated before reaching lexA. Only TU00435 is genuinely blocked.

Incorrect application of fold changes The fold change pipeline maps TF → gene name → all TUs containing that gene (via cistron_id_to_rna_indexes()). The lexA fold change is therefore applied to TU00352, TU00434, and TU00435 — including the two constitutive promoters that lexA cannot physically block. Only TU00435 should carry the lexA fold change.

Step 5 — Discover TU deduplication bug

Inspecting the actual parca-built simData.cPickle reveals that TU00434 and TU00435 do not exist in sim_data at all. Only TU00352 is present. This is caused by a deduplication step in reconstruction/ecoli/dataclasses/getter_functions.py:_build_rna_sequences: 

# Lines 249–270 (before any fix):
gene_tuple = tuple(sorted([gene_id for gene_id in tu["genes"] if gene_id in valid_gene_ids]))

if gene_tuple in gene_tuple_to_tu_index:
    # Merge evidence codes into the FIRST TU — then silently skip
    evidence_list.extend(...)
    continue       # ← TU00434 and TU00435 dropped here

TU00352, TU00434, and TU00435 all share the same three genes (EG10920/rpsU, EG10239/dnaG, EG10896/rpoD) → identical gene_tuple. TU00352 (lowest ID) wins; TU00434 and TU00435 are silently discarded.

Consequence dnaG has only ONE transcription unit in the model (TU00352). That TU carries the lexA fold change and has rna_synth_prob = 0.0000884 in the basal condition — approximately 38× lower than rpsU's dedicated single-gene TU (TU00472: 0.0033321). Unlike rpsU and rpoD, dnaG has no fallback constitutive TU.

9. Root Cause Analysis

The ~10–12× DnaG deficit results from four compounding errors:

  1. Inflated fold change magnitude — lexA → dnaG = −1.71 log₂ derived from SOS/norfloxacin conditions where lexA is fully cleaved. Represents maximum de-repression, not the constitutive lexA activity during normal growth.
  2. Fold change applied to constitutive promoters — TU00352 (rpsUp1) and TU00434 (rpsUp2) have TSSs upstream of the lexA operator. They are constitutively active and should not carry the lexA fold change. The cistron-level application in the parca applies it to all TUs indiscriminately.
  3. TU deduplication discards alternative promoters — The deduplication in getter_functions.py keeps only one TU per unique gene set. TU00434 (rpsUp2, the constitutive alternative) is silently dropped, leaving dnaG with no constitutive fallback TU.
  4. LexA is always active at runtime (0CS) — The suppression is never reversed. The SOS response (lexA cleavage by RecA under DNA damage) is not modelled. Even if the fold change were correct for the SOS context, it is permanently applied.

Systemic Scope

773 genes affected The cistron-level fold change application affects 773 genes in the current model that have multiple TUs at different transcription start sites. For genes whose TUs have genuinely different TSSs (upstream vs. downstream of the TF operator), the fold change is incorrectly applied to constitutive promoters. The dnaG/rpsU case is the most immediately impactful — a gene where the over-suppression directly causes cell death in multigeneration simulations.

Attempted Fix: TU Deduplication Change

A change to getter_functions.py was attempted to include the TU start position in the deduplication key: (gene_tuple, left_end_pos) instead of just gene_tuple. This correctly kept TU00434 and TU00435 as separate TUs.

Parca solver failure Restoring TU00434 and TU00435 caused the parca ECOS solver to fail with RuntimeError("Solver could not find optimal value") in fitPromoterBoundProbability. The root cause: parca assigns expression targets at the gene level, then maps them to TUs. With three TUs sharing the same genes, each receives the same expression target — the system becomes overconstrained (3× the total expression within [0, 1] probability constraints) and infeasible. The change was reverted. Fixing this properly requires modifying build_vector_k and build_matrix_G in fit_sim_data_1.py to distribute expression among co-TUs.

10. Fix Applied: tf_tu_exemption Variant

A post-parca variant was created at ecoli/variants/tf_tu_exemption.py that removes lexA's delta_prob contribution from specified TUs and absorbs it into basal_prob. This makes those TUs constitutively active — unaffected by lexA at runtime — while preserving the net transcription probability.

How it works

# For each exempt (TF, TU) pair:
# 1. Find the entry in delta_prob where deltaI == tu_i AND deltaJ == tf_j
delta_v = deltaV[entry_mask].sum()

# 2. Absorb delta into basal_prob (preserves net expression)
basal_prob[tu_i] += delta_v
basal_prob[tu_i] = max(0.0, basal_prob[tu_i])

# 3. Remove the entry from delta_prob entirely
keep &= ~entry_mask

Default Configuration

DEFAULT_EXEMPTIONS = {
    # lexA (PC00010): exempt TU00352 (rpsUp1) and TU00434 (rpsUp2)
    # Only TU00435 (rpsUp3, TSS downstream of operator) should be blocked
    "PC00010": ["TU00352", "TU00434"],
}

11. Next Steps & Known Limitations

Short-term (dnaG-specific)

  • Quantify variant improvement — variant 1 results are shown in Section 10 (Figs 11–13). Assess whether DnaG counts rise sufficiently above the 2/oriC threshold to sustain reliable initiation, or whether the partial fix still leaves the simulation borderline.
  • Remove lexA→dnaG from fold_changes_nca.tsv — the fold change was derived from SOS conditions, was never in the curated set, and is not appropriate for a model that does not simulate DNA damage. This would make dnaG constitutive at the parca level without needing a post-parca variant.
  • Cross-check translation efficiency — TE = 0.11 (3rd percentile; Li et al. 2014) seems low given the operon context. Worth verifying against independent ribosome profiling data.

Medium-term — Fix the parca co-TU expression problem

Required change Modify build_vector_k and build_matrix_G in reconstruction/ecoli/fit_sim_data_1.py to detect co-TUs (multiple TUs sharing the same gene set) and distribute the gene-level expression target among them rather than assigning the full target to each independently. This will allow the getter_functions.py deduplication fix to be reinstated, restoring TU00434 and TU00435 as distinct transcription units with correct promoter-specific regulation.

Medium-term — 0CS TF audit

  • Audit all 0CS TFs for inflated fold changes derived from conditions where the TF is artificially inactivated (knockouts, extreme perturbations) rather than from natural variation during normal growth.

Long-term — Architectural fix

  • TU-level fold change application — store genomic positions of TF operator sites alongside fold change data; apply fold changes only to TUs whose TSS is downstream of (or overlapping) the operator. Affects 773 genes in the current model.
  • SOS response module — model lexA cleavage by RecA under DNA damage. Currently, all lexA-regulated genes are permanently suppressed at the level dictated by the SOS-derived fold change. A DNA damage/SOS condition would allow de-repression in the appropriate biological context.
